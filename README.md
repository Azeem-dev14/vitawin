# 🌿 vitawin

A beautifully designed, modern iOS habit-tracking application built with SwiftUI and SwiftData. **vitawin** helps users cultivate positive routines and stay consistent with their daily goals in an intuitive, elegant interface.

---

## 🌟 Key Features

*   **Custom Habit Creation**: Add habits with custom names and emojis to represent them visually.
*   **SwiftData Persistence**: Local on-device storage ensuring your habit history is securely persisted across app launches.
*   **Minimalist UI**: Clean design that supports native dark mode and focuses on ease of use.
*   **Quick Delete**: Swiftly delete habits using standard list swipe actions.

---

## 🛠️ Architecture & Tech Stack

The project adheres to a clean, modular structure utilizing Apple's newest frameworks:

*   **UI Framework**: SwiftUI (Declarative UI)
*   **Persistence**: SwiftData (CoreData successor)
*   **Platform Target**: iOS 17.0+
*   **Development Tools**: Xcode 15.0+, Swift 5.9+

---

## 🚀 Getting Started

### Prerequisites

*   A macOS device running macOS Sonoma (14.0) or later.
*   [Xcode 15.0](https://developer.apple.com/xcode/) or later installed.

### Setup Instructions

1.  Clone the repository to your local machine:
    ```bash
    git clone https://github.com/yourusername/vitawin.git
    cd vitawin
    ```
2.  Open the project in Xcode:
    ```bash
    open vitawin.xcodeproj
    ```
3.  Choose your preferred simulator target (e.g., iPhone 15) or connect a physical iOS device.
4.  Build and run the application by pressing `⌘ + R` or clicking the **Play** button in Xcode.
